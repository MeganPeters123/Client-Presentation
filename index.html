How to use this dashboard
Loading the saved figures, updating them, and what to do when something looks wrong
1
If you only want to look at the figures
Two clicks, and nothing to upload

Go to the Data tab, sign in with your Aylett address under Saved history, then press Load latest. That pulls the whole saved history down and fills every tab. You do not need any files.

The figures stay in your own browser once loaded, so they are there next time. If the central copy has been rebuilt since, a bar appears at the top of the page offering Load latest again — that is the only thing that refreshes the numbers.

Signed out, the page shows nothing at all. That is deliberate: the figures can be read only once you are signed in, and none of them are stored in the page itself.

The monthly history is built from the valuation files by a script and pushed centrally, so in a normal month nobody needs to drag anything. The tiles are for the reference files above, for a fund whose file arrived late, and for trying something before it is built properly.

The Hedge Fund is the exception

Every other fund’s valuation lands in its folder by itself, overnight. The Hedge Fund’s month-end valuation does not: it has to be pulled from the Eagle portal by hand, and until someone does, the dashboard has nothing newer to show. That is why the Hedge Fund is usually the one carrying last month’s figure.

  1. Wait until Eagle has the month-end. It is not ready the moment the month closes, which is exactly why this step is a person and not a scheduled job. There is no harm in asking early — the script refuses to save anything if Eagle comes back with no data for that date.
  2. Run it. Double-click run_hedge_fund_monthend.bat in your own Eagle-Download folder, normally %USERPROFILE%\Eagle-Download. It asks which month you want and confirms before it submits anything, so nothing happens by accident.
    Use your own copy, not the one inside Brandons’ Folder. That one is shared through SharePoint, and the setup script in it rebuilds a Python environment that then syncs to everyone else, breaking it for them.
  3. Check the file arrived. It saves as YYYY.MM.DD - AYLHF01_C.xlsx, dated the last day of the month.
    Fund - Hedge\Monthly NAV\
  4. Then it is an ordinary holdings file. The monthly build already reads that folder, so the next rebuild picks it up and the carried-forward note disappears. To see it straight away without waiting for a rebuild, drag the file onto the Fund Holdings tile.

Until then nothing is wrong with the figures on screen — the Hedge Fund simply stands at its last month-end, and both the funds table and the consolidated total say so by name rather than quietly folding in a stale number.

4
Dragging files in
What to expect while it reads them
  • Drag a file onto its tile, or click the tile and pick it. Holdings, trades and attribution take several files at once.
  • A tile that has loaded turns green and says what it found — how many funds, how many months. If it does not, the file did not go in.
  • Everything is read in your browser. The files themselves are never sent anywhere.
  • While you are signed in, the SA revenue split, GICS, index weights and attribution are saved centrally, so the next person does not have to upload them again. The holdings history is not — that comes from the monthly build.
  • Save this period on the Overview tab keeps a month in this browser only. Use Export history (.json) and Import history to carry a set of figures to another machine.
5
Putting it in a pack
Every table and chart can be lifted out on its own

Hover over any numbered block for Copy and PNG, with a menu to take just the table, just the chart, or the whole step. Copy puts the picture straight on the clipboard to paste into a slide; PNG saves it as a file. The buttons themselves never appear in the picture.
